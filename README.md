# JELLYFISH HUNTER

海中を舞台にした 3D 弾幕シューティング（オンレール型・三人称後方視点）。
仕様は [`jellyfish-hunter-spec.md`](jellyfish-hunter-spec.md) に準拠しています。

3Dモデルは「子どものイラスト → 画像生成 → Meshy で3D化」で作られた 6 体の glb を使用しています。

## あそびかた

| 操作 | 動作 |
|---|---|
| **W A S D** | 自機の移動 |
| **左クリック長押し＋なぞる** | 敵をロックオン（複数可・マークは時間で消えない） |
| **左クリックを離す** | ロックオンレーザー発射 ＋ 僚機のホーミング弾を一斉発射 |
| **スペース** | 通常ショット ON / OFF（正面へオートファイア・威力は最弱） |
| **右クリック** | ボム（画面内の敵と弾を全消し／僚機を1体消費／CT 5秒） |
| **M** | サウンド ミュート切替 |
| **P / ESC** | ポーズ |

### 味方化システム
ロックオンした雑魚敵には**味方化マーク**が付きます。マーク付きの敵を倒すと
（レーザー／僚機弾／通常ショットのいずれでも）その敵が**僚機**になり、自機の周囲を
周回しながら自動でホーミング弾を撃ちます。最大 10 体。

僚機は**ライフを兼ねます**。被弾すると僚機を 1 体失い、2 秒の無敵時間＋点滅。
僚機 0 の状態で被弾するとゲームオーバー（ステージ最初から）。

なぞっている間は僚機の攻撃が止まり、クリックを離した瞬間にレーザーと僚機弾が
一斉に飛ぶ——というトレードオフが攻撃の核です。

### 周回要素
1 周クリアでタイトルに**武器セットアップ**と**HARD**が追加され、以後は永続保存されます
（`localStorage`）。

1. **通常ロックオン（強化版）** — なぞり型／ロックオン上限 6 → **10**／レーザー黄色
2. **強化ロックオン** — クリック一発で画面内を**最大 10 体**即時ロックオン／レーザー赤色

2 種は切り替え式で、出撃前にどちらかを選びます。

### 難易度

| | 解放 | 敵の数 | 雑魚耐久 | 中ボス／ボス耐久 | 弾速 | 発射間隔 | 増援 | ボスの追加攻撃 |
|---|---|---|---|---|---|---|---|---|
| **NORMAL** | 最初から | ×1 | ×1 | ×3 | ×1 | ×1 | なし | なし |
| **HARD** | 1周クリア | **×2** | ×1.55 | **×7.75** | ×1.28 | ×0.62 | あり | あり |
| **NIGHTMARE** | HARDクリア | **×3** | ×2.1 | **×12.6** | ×1.45 | ×0.44 | あり | あり（弾数増） |

中ボス／ボスの耐久倍率は NORMAL の素の値に対する倍率です（実数値は下表）。

| | 中ボス エイ | ボスクラゲ 合計 |
|---|---:|---:|
| NORMAL | 1,860 | 6,840 |
| HARD | 4,805 | 17,670 |
| NIGHTMARE | 7,812 | 28,728 |

HARD 以降は敵の数を横に広げるのではなく、同じ陣形を**奥行きに重ねて波状**にします。
さらに群れが途切れると自動で増援（`Stage.updateFiller`）が差し込まれるため、
手が空く時間がほとんどありません。

弾は1発ずつ時間差（`volleyGap`）と速度のばらつき（`speedJitter`）をつけて撃たれるので、
同時発射の「壁」ではなく弧を描いて迫ってきます。NIGHTMARE では雑魚が扇を二重に重ね、
エイは回転する全方位弾を撒きます。

ボスは HARD 以上で**攻撃トラックが2本**になり、メインの「あわ掃射」と並行して
追加攻撃（穴が1か所だけ開いた**弾の壁** / 回転して撒き続ける**渦** / 自機を狙う**速射**）を
順番に撃ってきます。ボス戦の同時弾数は NORMAL 約21発、HARD 約64発、NIGHTMARE 約111発です。

**触手を伸ばす攻撃**は重い一撃で、当たると僚機を**3体**失います（`CFG.boss.tentacleCost`）。

## 動かす

静的ファイルのみなので、HTTP で配信すればそのまま動きます（`file://` 直開きは
ES モジュールと glb の取得が CORS で失敗するため不可）。

```bash
npx http-server -p 8080 -c-1 .
# → http://localhost:8080/
```

**GitHub Pages**: Settings → Pages → Source を `main`（または任意のブランチ）の
`/ (root)` にするだけで公開できます。three.js は `vendor/` に同梱しているため
CDN への接続は不要です。

初回はモデル約 32MB を読み込むため、ローディングに時間がかかります。

## 構成

```
index.html              ゲーム本体（HTML / CSS / JS を1ファイルに同梱）
models/*.glb            自機・雑魚3種・中ボス・ボスの3Dモデル
vendor/                 three.js r180（module.min + core.min）, GLTFLoader, BufferGeometryUtils
jellyfish-hunter-spec.md 仕様書
```

`index.html` の先頭にある `CFG` / `HARD` 定数で、弾速・威力・僚機の周回半径・
ボス部位の耐久値・ハード時の弾幕倍率などをまとめて調整できます。
ブラウザのコンソールからは `JH`（`JH.CFG`, `JH.Game`, `JH.Boss` …）で
実行中の状態に触れます。

## 仕様書からの具体化メモ

仕様書の「未確定・要検討事項」および記載のなかった箇所は、以下のように決めています。
数値はすべて `CFG` / `HARD` に集約してあるので変更は容易です。

- **通常ショット**: 0.105 秒間隔で左右2発、1発 5 ダメージ。ロックオンレーザー 62 /
  僚機ホーミング弾 44 に対して明確に最弱の保険枠。
- **僚機**: 周回半径 3.4、周回速度 1.25 rad/s、0.42 秒間隔で自動発射。
- **初期僚機**: 仕様書に初期数の記載がないため **3 体**から開始（0 体だと初弾被弾で
  即ゲームオーバーになるため）。`CFG.wing.start` で変更可。
- **ボス部位耐久**: ツノ 430 ／ 触手 350×2 ／ 本体 1150（NORMAL 基準。HARD 以降は上表の倍率）。ツノと触手2本を破壊するまで
  本体へのダメージは 26% に減衰し、全部位を壊すと本体が露出します。部位を1つ壊すごとに
  雑魚召喚フェーズへ移行し、僚機を補充できます。
- **ボスの当たり判定**: 配布された `Boss_Jellyfish.glb` は単一メッシュでノード名も無いため、
  ツノ／触手L／触手R／本体は**モデル座標系に置いた4つの判定球**として定義しています
  （`Boss.makeParts()`）。モデルを差し替える場合はここのオフセットと半径を調整してください。
- **難易度**: 上の表のとおり。すべて `DIFF` テーブル1か所にまとまっているので、
  数値を書き換えるだけでバランス調整できます。ランクを増やすことも可能です
  （`DIFF` にキーを足して `DIFF_ORDER` に並べるだけ）。
- **被弾後の無敵時間**: **0秒**（仕様書の「2秒程度」から、テストプレイの要望で撤廃）。
  代わりに `CFG.player.hitTick`（0.12秒）でダメージ判定の最小間隔だけ設けています。
  これは無敵ではなく、1回の接触で僚機がフレーム数ぶん一気に溶けるのを防ぐためのものです。
  完全に 0 にしたい場合は `hitTick: 0` にしてください。
- **ロックオンレーザーの威力**: 140。どの難易度でも雑魚を1発で撃破できる値にしています
  （最も硬い NIGHTMARE のザコサメが 139）。ロックオンした雑魚は必ず落ちて味方化する、
  という設計を全難易度で成立させるためです。
- **ボムの消費**: 最も**古い**僚機から消費します。被弾で失うのは新しい方からです。
- **BGM / SE**: 外部素材を使わず WebAudio で合成しています（ステージ曲・ボス曲・
  エンディング曲を差し替え）。
- **エンディング**: Canvas2D で描いた海中の1枚絵に、実際の3Dモデル（自機＋生存した僚機）を
  透過レンダリングして合成しています。
- **タイトル**: 仕様書では未定のため、スペック名の `JELLYFISH HUNTER` を採用。
